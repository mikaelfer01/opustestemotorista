Contatos e Recomendacoes
Conectar Planilha de Tarifas
Cole a URL do Apps Script da sua planilha de tarifas. Quando conectado, os valores serao atualizados automaticamente sem precisar alterar o codigo.
Colunas esperadas na aba "Tarifas": uf | estado | regiao | jadlog | log | patrus | totalexpress | correios | fretebras | prazo
Regiao deve ser: nordeste, sudeste, sul, centro ou norte. Tarifa em R$/kg, prazo em dias uteis.
function doGet() { var sh = SpreadsheetApp.getActive().getSheetByName("Tarifas"); var data = sh.getDataRange().getValues(); var h = data[0]; var rows = data.slice(1).map(function(r){ var o={};h.forEach(function(k,i){o[k]=r[i];});return o; }); var out = JSON.stringify({ok:true,tarifas:rows}); if(arguments[0]&&arguments[0].parameter.callback) return ContentService.createTextOutput( arguments[0].parameter.callback+"("+out+")") .setMimeType(ContentService.MimeType.JAVASCRIPT); return ContentService.createTextOutput(out) .setMimeType(ContentService.MimeType.JSON); }
