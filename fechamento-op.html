Configurar etapas do OMIE
Cada empresa configura as etapas da Ordem de Produção de um jeito no OMIE (Configurações > Processo da Ordem de Produção). Se a OP está pulando direto para "Conferido", o código usado aqui para "Qualidade" provavelmente não é o mesmo configurado na sua conta. Use o diagnóstico abaixo para descobrir o código real antes de salvar.
Diagnóstico: consulta a OP selecionada agora no OMIE e mostra o código de etapa (cEtapa) que está gravado nela — compare com o que você vê na tela do OMIE para achar o valor certo.
